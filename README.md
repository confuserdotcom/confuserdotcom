Maths undergrad and olympiad trainee. I take my notes in Obsidian with Vim
keys and LaTeX, and I build the tools I need along the way.

### tock

[**tock**](https://github.com/confuserdotcom/tock) records what you work on,
on a Mac or on Linux under Hyprland, and labels it with rules you write. You
never start a timer, and your data stays on your machine.
[Docs](https://confuserdotcom.github.io/tock/) ·
`brew tap confuserdotcom/tock && brew install tock`

### Obsidian plugins

- [flash-jump](https://github.com/confuserdotcom/obsidian-flash-jump): flash.nvim-style jumps in Vim mode, even inside rendered maths.
- [latex-objects](https://github.com/confuserdotcom/obsidian-latex-objects): Vim text objects, jumps and edits for LaTeX.
- [pdf-zathura](https://github.com/confuserdotcom/obsidian-pdf-zathura): zathura's keys in the PDF view.
- [vim-extras](https://github.com/confuserdotcom/obsidian-vim-extras): spelling keys, screen-row numbers, Ctrl-N / Ctrl-P in menus.

### Other

- [ilhop](https://github.com/confuserdotcom/ilhop): one key hops pointer and keyboard between a Hyprland box and a Mac.
